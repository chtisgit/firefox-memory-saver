v0.3.1:
* Fix slow popup and settings loading when recorded activity history grows.
* Previously recorded activity history is cleared by this update. Settings,
  protected tabs, recent sleep information, and lifetime discard totals are
  preserved. Recording starts fresh if enabled.

v0.3.0:
* Automatic discarding now keeps more tabs loaded for the same "Keep at least"
  setting: active and protected tabs no longer count toward either minimum.
  For example, a per-window minimum of 2 now keeps 2 inactive, unprotected tabs
  loaded in addition to the active tab and any protected tabs. This change also
  applies to manual discarding.
* Add a This Tab section showing the page title, favicon, URL, protection status,
  and a button to protect or unprotect the current tab.
* Show when the current tab last went to sleep and, when activity recording is
  enabled, how much time it has been active.
* Make the popup more compact and prevent long sleeping/protected tab lists
  from overflowing it.
* Add a minimum number of tabs to keep loaded across all windows, alongside the
  per-window minimum. Both minimums can now be set to zero.
* Replace the two discard buttons with "Discard N now", showing how many tabs
  can be discarded across all windows. Hide the button when none are eligible.
  Manual discarding respects protections and minimums but does not wait for
  the inactivity timeout.
* Show a message when Firefox refuses to discard tabs or discarding fails.
* Choose how often to check for unused tabs automatically, based on the
  "Discard tabs after" setting, instead of requiring a separate setting.
* Add Restore Default Settings and ask for confirmation before clearing
  recorded activity data. Show allowed input ranges beside settings labels.
* Change the default activity-history retention to 14 days and allow up to
  365 days. Keep existing saved preferences.
* Improve active-time totals so duplicated tabs have their own history and
  totals cover only the selected history period.
* Expand optional local activity recording to include when and how often tabs
  go to sleep, preparing for browsing-history review tools in a future release.
  Recording remains off by default; review pages are not included yet.
* Drop Firefox for Android support: the extension does not appear to work well
  there, and Android already seems to unload tabs more aggressively.

v0.2.0:
* Added a Memory Saver submenu to the tab context menu.
* Protect an individual tab with "Do not discard this tab". Per-tab protection
  follows the tab across normal Firefox restarts and session restoration.
* Protect a website with "Do not discard <domain>". This adds the domain to the
  existing excluded-domain settings, and both context-menu actions can be
  reversed with their corresponding "Allow discarding" action.
* Added Sleeping tabs and Protected tabs views to the popup, with live counts
  for both. Sleeping tabs remains selected by default.
* The Protected tabs view lists every open tab protected by a manual rule,
  protected domain, pinned-tab setting, audible-tab setting, or special-page
  safety rule, together with its last-accessed time and applicable protection
  reasons.
* Increased the popup width to give tab titles and protection details more room.

v0.1.2:
* Manifest changes.

v0.1.1:
* Automatically unload inactive tabs after a configurable amount of time.
* Choose how frequently Memory Saver checks for unused tabs.
* Keep a minimum number of tabs loaded in each window.
* Protect pinned tabs and tabs playing audio.
* Protect specific websites and domains from being unloaded.
* Manually unload eligible tabs across Firefox or only other tabs in the current window.
* View all currently sleeping tabs in one convenient list.
* Restore or close sleeping tabs directly from the popup.
* Optionally record local foreground active-tab time with configurable retention.
* Clear locally stored activity data at any time.
* No advertisements, tracking, analytics, or data transmission.
* No access to webpage contents.
* Open-source software.
